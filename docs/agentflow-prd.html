01 / Positioning

产品定位

AgentFlow 面向希望在本机掌控 AI 处理流程的个人用户，提供一个"画布 + 运行台"的工作空间：用图形方式编排模型调用、外部请求与条件分支，并在本机完成执行、观测与复盘。

维度描述
目标用户独立开发者、研究者、内容与运营人员等单机使用者。通常已具备模型 API Key 或本地推理服务，愿意自己配置环境。
使用场景把"抓取资料 → 模型总结 → 条件校验 → 输出成稿"这类多步骤任务固定下来，重复运行、对比结果、定位失败节点。
核心价值过程可见。每一步的输入、输出、耗时与消耗都可回看；改一处配置即可复跑，不必重新拼装脚本。
使用环境Windows 桌面应用，Electron 壳内嵌 FastAPI + React。无账号体系、无云端同步、无多租户。断网时除模型与外部请求外，其余功能均可用。
不在定位内团队协作、权限分配、线上 SaaS 计费、公开市场化的模板商店。
设计基调：单用户意味着可以省去登录、邀请、角色与审批流程；产品应把复杂度全部让位给"编排"和"观测"两件事，而不是复制一套企业后台。

02 / Product Contract

产品契约

要素定义
唯一角色本机使用者。拥有本机全部工作流、密钥与运行记录；不存在第二个角色，也不存在"分享给他人"的动作。
触发使用者打开桌面应用，新建工作流或从列表打开一个已有工作流。
核心任务把一次多步骤 AI 处理编排成图，并让它在需要时稳定地跑完。
完成条件一次运行到达"成功"，且使用者能在运行记录中查看每个节点的输入、输出与耗时；任务结果可被复制或下载。
共享对象工作流：由节点与连线构成的图，是编排、运行与复盘共同指向的唯一对象。
信任基础使用者信任"所见即所跑"：画布上的结构与实际执行的步骤一致；日志不做美化，失败如实暴露。

03 / Concepts

核心概念

概念定义边界说明
工作流一张有向无环图，包含节点、连线、工作流级输入与输出定义。必须无环；至少一个入口与一个出口才能运行。
节点图中的一个执行单元，有类型、参数、输入端口与输出端口。每个节点拥有稳定 ID；改名不影响引用。
连线表示数据流向：上游节点的输出成为下游节点的输入来源。不允许自环、重复连线、跨层回连。
变量对工作流输入或某个节点输出的引用，写作 {{ 名称.字段 }}。只在文本参数中生效；解析失败按规则报错，不静默替换为空串。
运行一次按图执行的实例，记录整体状态与逐节点结果。运行只读快照，不受之后对工作流的编辑影响。
快照运行发起时固化的工作流结构副本。回看旧运行不展示"当前"节点配置，避免误读。

04 / Scope

范围界定

P0 只覆盖"进入 → 编排 → 校验 → 调试 → 运行 → 复盘"这一条完整旅程；任何不能支撑完成或恢复的功能都不进入本期。

级别内容
P0工作流列表与增删改复制；画布拖拽编排与连线；七类基础节点；变量引用；全量运行与单节点调试；运行记录与节点级日志；模型与密钥配置；本机设置与数据备份。
P1版本历史与对比；工作流导入导出（JSON）；定时触发；本地文档知识库检索节点；人工确认节点；子工作流复用；运行结果对比；Electron 桌面壳 + 自动更新。
不做多用户与权限；云端同步与分享链接；在线模板市场；计费与账单；移动端专用布局。

05 / Functional Requirements

功能需求

每项需求按"触发 — 处理规则 — 结果 — 状态变化"描述；共享规则（连线校验、变量解析、状态机）只在第 7 章定义一次。

5.1 工作流管理

能力规则
列表展示全部工作流：名称、简介、节点数、最近一次运行状态与时间。支持按名称搜索，按"全部 / 草稿 / 已就绪"筛选，按最近编辑与最近运行排序。
新建提供空白工作流与内置模板两种入口。新建后直接进入画布，工作流处于"草稿"。
重命名名称在工作流内唯一；留空或重名时阻止保存并原地提示。
复制复制结构、节点参数与工作流级输入定义；不复制运行记录与密钥引用以外的敏感值，副本名称追加"副本"。
删除删除前需二次确认，并明确提示"将一并删除该工作流的全部运行记录"。删除不可撤销。
自动保存画布编辑在停顿后自动保存草稿；工具栏显示"已保存 / 保存中 / 保存失败"三种反馈。保存失败时保留本地未提交修改并提示重试。

5.2 画布编排

  • 节点库：左侧固定面板，按"基础 / 模型 / 工具 / 流程"分组，支持关键字过滤；点击或拖拽均可添加节点，新节点落在视口中心附近并保持选中。
  • 连线：从输出端口拖向输入端口建立连接；端口类型不兼容时，目标端口在悬停期间显示为不可用。
  • 选中与属性：单击节点选中，右侧属性面板展示该节点参数、可用变量与最近一次运行输出；单击画布空白处取消选中。
  • 结构操作：支持框选、多选移动、删除、复制粘贴、撤销与重做；撤销栈覆盖节点增删、连线、位置与参数修改。
  • 视图：支持缩放、平移、适应画布、自动布局（按拓扑分层从左到右排列）。缩放与自动布局不改变业务数据。
  • 校验入口：工具栏常驻"校验"，也可在运行前自动执行一次；校验结果以列表形式定位到具体节点。

5.3 节点类型

节点参数行为与输出
输入字段名、类型（文本 / 数字 / 布尔 / JSON）、是否必填、默认值、说明。运行开始时作为工作流输入被填写；输出为该字段集合。同一工作流可存在多个输入节点。
LLM 调用模型、系统提示、用户提示、温度、最大输出长度、输出格式（文本 / JSON）。按解析后的提示调用模型；输出为文本或结构化对象，并附模型名、耗时与 token 用量。调用失败时按重试规则处理。
结构化抽取模型、待抽取内容、目标字段列表、字段说明。输出为字段对象；无法按目标字段解析时标记为节点失败，并保留原始响应以便排查。
HTTP 请求方法、地址、查询参数、请求头、请求体、超时秒数。输出为状态码、响应头与响应体（自动识别 JSON）；非 2xx 视为失败，但响应体仍完整保留。
Python 脚本脚本内容、超时秒数。在受限的本机运行环境内执行，输入通过变量注入，输出取脚本返回的 JSON；异常信息原样呈现。
条件分支左值、比较符（等于 / 不等于 / 包含 / 大于 / 小于 / 为空判断）、右值。输出布尔结果，并只激活满足条件的那一条下游分支；未激活分支上的节点标记为"已跳过"，不视为失败。
合并合并策略（全部到达 / 任一到达）、结果字段名。收拢多条上游结果后统一输出，供下游一次性使用。
输出结果字段名、来源变量、展示格式（文本 / JSON / Markdown）。运行完成时作为最终结果展示，可复制与下载。

节点通用设置：名称、启用开关、失败重试次数（0–3）、超时（继承工作流默认或自定义）、备注。停用的节点在运行中标记为"已跳过"，其下游若无其他输入来源则整体跳过。

5.4 变量引用

  • 引用格式为 {{ 引用源.字段路径 }}，引用源可以是工作流输入名，也可以是节点名称；字段路径用 . 逐级访问，数组下标写作 [0]。
  • 属性面板在文本输入框旁提供"可用变量"列表，点击即插入；插入位置为光标处。
  • 引用不存在的字段时，该节点在运行前校验阶段即被标记为错误，并给出可定位的提示；运行中若上游输出结构与预期不符，节点失败并保留原始上下文。
  • 变量值以字符串化结果注入提示词；对象与数组按 JSON 文本注入，避免歧义。

5.5 运行与观测

能力规则
发起运行画布工具栏"运行"发起一次全量运行；若存在必填输入未填写，先弹出输入表单，填写完成才可开始。
运行中反馈节点按执行顺序显示"排队 / 运行中 / 成功 / 失败 / 已跳过 / 已取消"；当前节点高亮，连线在数据通过时短暂高亮。
实时日志底部运行面板追加节点级日志（开始、结束、模型与 token、错误摘要）。使用者可折叠、清空显示（不清除记录）与复制。
取消运行中提供"取消"；已完成的节点结果保留，正在执行的节点标记为已取消，未开始节点标记为已取消。
超时单节点超时按节点设置执行；整次运行不设统一上限，但连续超时导致全部节点结束后运行状态为失败。
完成反馈运行结束后展示整体耗时、成功节点数、失败节点数与 token 总量；存在失败节点时，定位到第一个失败节点并展开其错误详情。
结果取用输出节点结果支持一键复制；JSON 结果支持下载为文件。历史运行可随时重新打开。

5.6 节点调试

  • 属性面板提供"调试运行此节点"：仅执行该节点，上游输入取该节点变量的最近一次成功输出，若无则要求手动填写。
  • 调试结果就地展示在该节点的"输出"标签页，不写入正式运行记录，也不改变工作流状态。
  • 调试失败时展示错误类型、错误信息与所使用输入，便于判断问题出在参数还是上游数据。

5.7 模型与密钥

能力规则
服务商支持"OpenAI 兼容"（自定义服务地址与模型名）、"Ollama 本地"与"Anthropic 兼容"三类配置。每类可添加多个实例。
连接测试保存前可"测试连接"，返回成功或具体错误（地址不可达、鉴权失败、模型不存在、超时）。测试结果不改变已保存配置。
密钥展示密钥仅在本机保存；界面只显示尾号（如 ••••3f9a），编辑时需重新输入完整值。密钥不随工作流导出、不写入运行日志。
默认模型可指定一个默认模型；新建 LLM 节点时预选该模型，逐节点仍可覆盖。
可用性提示工作流引用的服务商被删除或停用时，该校验项报错并指明受影响的节点，不阻止查看历史运行。

5.8 运行记录

  • 列表展示：运行编号、所属工作流、状态、触发方式（手动 / 调试 / P1 定时）、开始时间、总耗时、token 总量。
  • 筛选：按状态、工作流与时间范围；默认按开始时间倒序。
  • 详情包含：整体摘要、逐节点时间线、每个节点的输入与输出快照、错误堆栈摘要、所用模型与 token。
  • 支持"以此配置重新运行"：使用该次运行的快照结构与输入重新发起，产生新的运行编号。
  • 运行记录按工作流保留最近 200 条；超出后最旧记录自动清理，清理前在设置中提示保留策略。

5.9 本机设置

  • 展示数据目录与占用大小，提供"打开目录"与"导出备份"。
  • 自动保存开关、运行日志保留条数、默认超时时间、界面语言。
  • 导入工作流：选择本地 JSON 文件，先预览将新增的工作流与校验结果，确认后才写入。
  • 危险操作：清空全部运行记录、清空全部数据。两者均需输入确认文字，且明确不可恢复。

06 / Flows

关键流程

主流程 — 从空白到一次成功运行

01新建选择空白或模板，进入画布，状态为草稿。
02编排拖入节点、连线、填写参数与变量。
03校验检查必填项、连线与变量引用。
04调试对关键节点单步执行，确认输出结构。
05运行填写工作流输入，观察节点状态与日志。
06复盘查看结果与节点快照，必要时重新运行。

恢复流程 — 运行失败：运行失败后，界面定位到第一个失败节点；使用者可查看错误与输入快照，选择"调试此节点"验证修正，再发起新的运行。旧运行记录保持原样，供对比。

恢复流程 — 保存失败：工具栏出现"保存失败 · 重试"，本地编辑内容保留；重试成功后状态回到"已保存"，期间不阻止继续编辑，但关闭页面前给出未保存提示。

07 / States

状态与规则

工作流状态

状态进入条件允许动作
草稿新建或存在未完成的校验问题。编辑、保存、调试单节点、尝试运行（运行前自动校验）。
已就绪校验通过：无环、至少一个输入与一个输出、必填参数完整、变量可解析。运行、复制、编辑（编辑后回落为草稿）。

运行状态机

状态含义后续
等待输入已发起但必填工作流输入未填写。填写后进入"运行中"；关闭则回到未运行。
运行中至少一个节点正在执行。全部终态后进入 成功 / 失败 / 已取消。
成功所有应执行节点成功，或仅有被跳过节点。终态。
失败存在至少一个失败节点。终态；可重新运行。
已取消使用者主动取消。终态。

节点状态

状态说明
排队上游尚未产出所需输出。
运行中已开始执行，尚未产出结果。
成功产出有效输出。
失败执行出错且重试耗尽，或参数/变量解析错误。
已跳过所在分支未被激活，或节点被停用。不计入失败。
已取消运行被取消时该节点尚未完成。
一致性规则：一个节点在执行前必须拿到全部必需输入；条件节点只有一个下游分支会被激活；被跳过节点不阻断运行；运行的最终状态只由"是否存在失败节点"和"是否被取消"决定。

08 / Edge Cases

异常与边界

场景系统行为
存在环校验失败，提示"检测到循环依赖"并高亮构成环的连线；禁止运行。
节点未连线孤立节点在校验中提示"未连接到主流程"，可选择停用或删除。
缺少必填输入运行前拦截并打开输入表单；表单提交后校验通过才继续。
模型未配置 / 密钥失效运行时该节点失败，错误写明"服务商未配置"或"鉴权失败"，并跳转模型设置入口。
接口限流或超时按节点重试次数重试，每次间隔递增；仍失败则节点失败，保留最后一次响应。
外部地址不可达HTTP 节点失败并记录耗时与错误原因；不影响其他已成功节点的结果留存。
取消时的中间态正在执行的节点尽快终止并标记已取消；已产生的结果仍可查看。
空工作流画布展示空状态引导（"从左侧拖入输入节点开始"）；不可运行。
删除被引用的节点连线一并移除，引用该节点的变量在校验中标红，提示需更新。
导入冲突同名工作流默认生成副本名，不覆盖已有工作流。
数据目录不可写保存与运行记录写入失败时给出显式错误，进入只读提示，不静默丢弃内容。

09 / Trust & Security

权限与安全

  • 单用户边界：无注册、登录与角色；Electron 壳在本机进程内运行，FastAPI 仅监听 127.0.0.1，外网完全不可达。
  • 密钥：仅在本机存储，界面与日志均不出现完整值；导出工作流时不包含密钥。
  • 数据流向：模型请求仅发往使用者配置的服务商；产品本身不上报任何使用数据。
  • 脚本节点：通过独立子进程执行（python -I -S），工作目录为临时目录，超时即 kill，避免影响主进程。
  • 删除：删除工作流、清空运行记录、清空数据均为不可逆动作，需二次确认。
  • 导入：导入文件只创建内容，不自动执行；导入后先校验，由使用者决定是否运行。

10 / Non-functional

非功能要求

类别要求
启动桌面壳启动后 10 秒内可打开工作流列表；无需额外数据库或中间件安装。
交互画布拖拽与缩放保持连贯；100 个节点以内的图操作不出现明显卡顿。
可靠性自动保存失败不丢失当前编辑；取消运行不产生"卡在运行中"的垃圾状态；后端崩溃时主进程自动重启它。
可移植数据目录可整体复制到另一台同版本机器继续使用；支持导出备份。
可读性日志与错误使用平实中文，不暴露内部堆栈作为唯一说明；保留原始错误供排查。
