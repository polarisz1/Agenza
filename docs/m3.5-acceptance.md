```bash
pnpm install
uv sync --directory apps/api --all-extras

# 终端 A

# 终端 B
pnpm dev:web          # http://localhost:5173
```

打开 <http://localhost:5173>。

## 1. 主链路（PRD §6）

| # | 操作 | 预期 |
|---|---|---|
| 1.1 | 工作流 → 新建 → 空白工作流 | 打开编辑器，画布为空并提示"从左侧拖入输入节点开始" |
| 1.2 | 拖入 输入 → LLM → 输出，连两条线 | 连线成功；把 extract/http 拖到输入上时端口不兼容应被拒绝 |
| 1.3 | 选中 LLM，属性面板填 prompt、选服务商 | 面板同步；顶部出现"未保存"，2s 后变"已保存" |
| 1.4 | 点"校验" | 通过（或有清楚的提示列表，点条目会定位到节点） |
| 1.5 | 点"▶ 运行" | 弹出输入表单（若有输入节点）→ 运行后底部抽屉实时出现节点状态 |
| 1.6 | 运行结束 | 节点状态为成功/失败/跳过；抽屉里有耗时与 token |

> 没有可用模型时，1.5 应该看到节点**失败**且错误写明"服务商未配置/未找到"，
> 而不是整个页面报错。

## 2. 条件分支（T3，本次重点回归）

| # | 操作 | 预期 |
|---|---|---|
| 2.1 | 拖入 条件 节点 | 卡片右侧有**两个**端口，分别标"真""假" |
| 2.2 | 从"真"端口连到节点 A，从"假"端口连到节点 B | 两条边都能连上，边上显示"真"/"假"标签 |
| 2.3 | 设置条件为必然成立（如 `a` 等于 `a`），运行 | **只有 A 执行**；B 显示"⊘ 已跳过"，抽屉里写明"分支未激活" |
| 2.4 | 把条件改成必然不成立，再运行 | 反向：B 执行、A 跳过 |
| 2.5 | 删掉"假"分支的连线，点校验 | 出现提示级问题"条件节点的「假」分支没有连线"，**不阻断**运行 |
