## 1. 验收项（每家 5 条）

| # | 用例 | 通过标准 |
|---|---|---|
| 1 | 普通对话（非流式） | 返回文本；`model`/token 正确；节点成功 |
| 2 | JSON 模式 | LLM 节点 `format=json` 或抽取节点返回对象；解析失败有可读错误 |
| 3 | 流式 | 运行抽屉在结束前出现增量文本；最终输出与增量拼接一致 |
| 4 | 鉴权失败 | 401/403 → 节点错误分类"鉴权失败" + 去模型配置 |
| 5 | 超时 / 连接失败 | 超时 → "执行超时"；地址不可达 → "网络连接失败" |

## 3. 怎么补跑（有环境时）

1. 在「模型配置」添加服务商（填真实地址/Key/默认模型），点「测试」应成功。
2. 用内置模板「文本摘要（LLM）」运行一次：确认流式文本与最终输出。
3. 把模型名改错再运行：应出现"模型或接口不存在（HTTP 404）"。
4. 把地址改成 `http://127.0.0.1:9/v1`：应出现"网络连接失败"。
5. 把 Key 改错：应出现"鉴权失败（HTTP 401/403）"，并能跳转模型配置。
6. 每条结果回填 §2 表格（✅/✗ + 错误原文），作为 v0.2 发布证据。
