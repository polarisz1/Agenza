## 5. 升级说明

- 启动时自动执行 alembic 0003：新增 `workflow_version` 表，`run` 增加 `version_id/version_seq` 两列（可空）。
- 已有工作流不会补历史版本；**下一次图变更**时开始生成 v1/v2…（首个快照以当前图为准，
  因此恢复功能对老工作流从下一次保存起可用）。
- 版本快照存完整图 JSON，不存节点运行输出；恢复只回退图与视口，不回退运行记录。

## 6. 手工验收脚本（10 分钟）

1. 新装/清空数据启动 → 自动弹首次引导 → 不配模型 → 选「Python 数据处理」→ 示例运行成功 → 打开编辑器。
2. 编辑器拖入 LLM 节点 → 属性面板选服务商 → 模型下拉自动加载（无 Key 时可手输）。
3. 运行一个 Python 模板 → 抽屉出现节点状态与最终输出；详情页看到输入/输出/耗时。
4. 连续运行两次 → 运行记录勾选两条 → 「对比选中」→ 看到耗时差与输出 diff。
5. 改图后保存 → 「版本」→ 预览旧版（只读画布）→ 恢复 → 画布回退且新增一条"恢复到 vN"。
6. 浏览器缩到 1100 宽 → 工作流/运行列表操作列仍在右侧，不被裁切。
7. 断开后端 → 顶部出现"无法连接后端"常驻条；恢复后 30s 内消失。
